## 개요

※이 글은 유니티 다이얼로그 시스템 에셋 ‘Naninovel(나니노벨)’의 한국어 번역 페이지입니다.

※모든 내용의 저작권 및 내용의 책임과 권한은 Naninovel에 있습니다.

※원문 페이지: [(링크)](https://naninovel.com/guide/game-settings)

---

[<https://naninovel.com/imgit/fetched/i.gyazo.com-8ef1044cb0b8429298af05e6275ff14d.mp4>](https://naninovel.com/imgit/fetched/i.gyazo.com-8ef1044cb0b8429298af05e6275ff14d.mp4?_=1)

사용 가능한 텍스트 폰트 옵션은 UI 구성 메뉴에서 설정됩니다.

![](https://subculturegamer.com/wp-content/uploads/2024/10/나니노벨-game-settings-2.avif)
> **메모**
>
> 글꼴 및 텍스트 크기 변경의 영향을 받아야 하는 텍스트 요소를 지정하려면 UI 프리팹(CustomUI 컴포넌트)의 *Font Change Configuration* 프로퍼티를 사용하세요. 기본적으로 텍스트 프린터만 영향을 받습니다. [커스터마이징 가이드](https://naninovel.com/guide/user-interface#ui-customization)에서 사용자 정의 UI 수정 및 생성에 대한 자세한 내용을 찾아보세요.

설정은 게임 디렉터리에 저장된 Settings.json 파일로 직렬화됩니다. 파일 이름은 *Naninovel -> Configuration -> State* 상황에 맞는 메뉴를 사용하여 구성할 수 있습니다. 사용 가능한 옵션은 [구성 가이드](https://naninovel.com/guide/configuration#state)를 참조하세요.

![](https://subculturegamer.com/wp-content/uploads/2024/10/나니노벨-game-settings-1.avif)

WebGL 설정에서는 크로스 브라우저 [IndexedDB API](https://en.wikipedia.org/wiki/Indexed_Database_API)를 사용하여 직렬화됩니다.

메뉴 UI는 [UI 커스터마이징](https://naninovel.com/guide/user-interface#ui-customization) 기능을 사용하여 원하는대로 구성하거나 완전히 교체할 수 있습니다.
