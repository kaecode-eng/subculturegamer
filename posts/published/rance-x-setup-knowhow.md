## 개요

Rance X (또는 Rance 10) 설치 방법에 관해 안내한다.

### 주의

- 본 게시물은 성적인 표현을 포함하고 있지는 않으나, 오직 **18세 이상 이용자**를 위해서만 작성되었음.
- 본 게시물은 2025년 하반기를 기준으로 작성되었음.
  - 설치 가이드 내에 포함되지 않은 내용은 답변드리기가 어려운 점 양해 부탁드립니다.

## 사전 준비물

### 게임 파일

게임 설치를 위한 이미지 파일을 준비한다.

여기서 말하는 이미지란, 쉽게 말하면 .jpg나 .png 등의 비주얼 이미지가 아니라 게임 파일을 의미한다.

게임 파일 확장자는 다를 수 있으나, 기본적으로 ‘반디집’ 등 압축해제프로그램으로 열리는 이미지 파일이 있어야 진행이 가능하다.

(게임 파일은 본인이 구해 오셔야 합니다.)

- Rance 10 본편 (iso, mdf, mds 등 이미지 파일 포함)
- 대표 구매처

## 설치 방법

### 1. 이미지 파일 압축 해제

![Rance X -결전- 설치 방법 - 이미지 압축 해제](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-01-1024x552.png)

압축 프로그램 (반디집 등)으로 게임 본편 이미지 파일을 연다.

파일이 정상적으로 열린다면, 압축을 해제한다.

> ※권장: ‘반디집’을 사용하고 계시다면, ‘코드페이지’ 항목을 ‘일본어’로 설정하고 압축 해제를 권장합니다.

### 2. 로케일 에뮬레이터로 ‘StartMenu’ 파일 실행

![Rance X -결전- 설치 방법 - 로케일 에뮬레이터](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-02-1024x686.png)

---

```
StartMenu.exe - 마우스 우클릭 - (윈도우 11의 경우 '추가 옵션 표시') - 로케일 에뮬레이터 - Run in Japanese(Admin) 선택
```

위 절차대로 StartMenu 파일을 로케일 에뮬레이터로 실행한다.

만약 로케일 에뮬레이터를 아직 설치하지 않았다면 미리 설치한 뒤 진행한다.

※로케일 에뮬레이터 설치 방법 가이드 링크: [(링크)](https://tg.cherrytree.info/95)

※Run in Japanese가 아니라 **Run in Japanese(Admin)으로 실행**합니다. 그렇지 않으면 예기치 않은 오류가 발생할 수 있습니다.

---

![Rance X -결전- 설치 방법 - 인스톨](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-03.png)

위 이미지처럼 ‘일본어’로 된 팝업이 노출되면 정상이다.

※만약 일본어가 아니라 ???나 궭뷁웱 등, **일본어가 제대로 표시되지 않는다면 로케일 에뮬레이터가 정상적으로 동작하지 않은 것**이다. 이후 원활한 설치 진행을 위하여 ‘로케일 에뮬레이터’ 정상 작동은 꼭 확인한 뒤 진행한다.

### 3. 게임 인스톨러에서 ‘인스톨’ 진행

‘인스톨（インストール）’ 버튼을 눌러 게임 설치를 진행한다.

아래와 같은 팝업이 정상적으로 노출되는지 확인한다.

![Rance X -결전- 설치 방법 - 인스톨러](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-04.png)

게임 설치 경로는 자유롭게 설정해도 무방하나, 이후 한글화 진행 예정이라면 아래 경로를 권한다.

```
C:\Rance10
```

만약 ‘오마케(게임 올 클리어 파일 등)’를 설치할 계획이 있다면, 세이브 폴더 위치를 본인이 편한 경로로 설정한다.

개인적으로는 ‘인스톨 폴더’를 추천한다. 여기에 설치해야 나중에 인스톨 폴더를 찾기가 쉽다.

#### 팝업 케이스 1: 세이브 파일을 인스톨 폴더에 설치하고, 게임 설치 경로를 Program Files 폴더 내에 설치할 경우

![Rance X -결전- 설치 방법 - 인스톨러 팝업](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-05.png)

```
ProgramFiles 폴더 내에 인스톨 할 경우, 인스톨 폴더 내에 세이브 파일이 만들어지지 않습니다. 그 외의 경로로 변경해 주세요.
```

위와 같은 팝업이 발생하는 경우, 설치 경로를 변경해 주시거나 세이브 파일 경로를 변경한다.

#### 팝업 케이스 2: 인스톨 경로가 C:\ 이하가 아닌 경우

![Rance X -결전- 설치 방법 - 인스톨러 팝업 2](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-06.png)

```
인스톨 위치가 외장식 HDD 등인 경우, 뜻밖의 경우에 의해 드라이브 문자가 변경되어 언인스톨이나 업데이트가 불가능하게 될 수 있습니다.

이대로 이 경로에 인스톨을 진행하시겠습니까?
```

위와 같은 팝업이 발생하는 경우, 설치 경로를 C:\ 이하의 특정 경로로 수정해주시거나 리스크를 인지하고 무시해도 무방하다.

![Rance X -결전- 설치 방법 - 인스톨러 팝업 3](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-07.png)

```
인스톨 폴더 E:\1. Gameroom\ランス１０이 존재하지 않습니다.
폴더를 생성하시겠습니까?
```

게임 설치 시 해당 경로에 이미 생성된 폴더가 없다면 위와 같은 팝업을 보게 된다.

웬만해서는(?) 게임 설치 전에 해당 경로에 폴더를 미리 만드는 경우도 없고 그럴 이유도 없으니 그냥 무시해도 된다.

![Rance X -결전- 설치 방법 - 인스톨러 팝업 4](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-08.png)

위에서 ‘예’ 버튼을 누른다면 위처럼 게임이 설치되기 시작합니다.

![Rance X -결전- 설치 방법 - 인스톨러 팝업 5](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-09.png)

위와 같은 팝업이 뜨면 정상적으로 설치된 것입니다.

![Rance X -결전- 설치 방법 - 게임 실행 타이틀](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-10-1024x603.png)

바탕화면에 있는 ランス１０(바로가기)를 선택하거나 설치 폴더로 가 설치 파일을 마우스 우클릭 해, 로케일 에뮬레이터로 실행한다.

이때도 설치할 때와 마찬가지로 로케일 에뮬레이터 내의 Run in Japanese (또는 Run in Japanese Admin)으로 실행한다.

※일본어로 출력될 것으로 예상되는 모든 프로그램은 ‘로케일 에뮬레이터’로 실행한다. 가령, 란스 10 실행 파일, 란스 10 공식 업데이트 파일 등은 게임사인 Alicesoft에서 제작하였으니 일본어로 출력될 것이므로 이런 파일은 로케일 에뮬레이터로 실행한다.

### 4. 업데이트 파일 압축 풀기

![Rance X -결전- 설치 방법 - 업데이트 파일 압축 풀기](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-11.png)

위에서 첨부한 ‘게임 업데이트’ 파일 1.01, 1.02, 1.04를 다운받는다.

각 업데이트 파일은 이전 업데이트가 설치되어 있어야 정상적으로 설치된다.

예를 들어, 1.04 업데이트 파일을 설치하려면 1.02 업데이트 파일을, 1.02 업데이트 파일을 설치하려면 1.01 업데이트 파일을 미리 설치해야 한다.

(단, 1.03 업데이트 파일은 1.04 버전 내에 포함되어 있으므로 건너뛰어도 됩니다.)

위에서 다운로드 받은 모든 폴더의 압축을 각각 풀어준다.

※이때 반디집에서 ‘코드페이지’ 항목을 ‘일본어’로 바꿔주면 아래처럼 폴더 내 파일명이 깨진 문자 없이 일본어로 정상 출력된다.

---

### 5. 업데이트 파일 순차 실행

![Rance X -결전- 설치 방법 - 업데이트 파일 순차 실행](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-12.png)

1.01, 1.02, 1.04 버전 폴더를 각각 압축풀기하면, 위처럼 Update.exe 파일이 있다.

이 파일을 로케일 에뮬레이터의 Run in Japanese (Admin) 버튼으로 실행한다.

![Rance X -결전- 설치 방법 - 업데이터 팝업](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-13.png)

```
이 업데이트 파일은 '란스 10' 전용입니다. 버전 1.01으로 업데이트 하시겠습니까? (세이브 데이터는 이대로 사용하실 수 있습니다.
```

위 팝업에서 ‘예’ 버튼을 누르면 업데이트가 진행된다.

![Rance X -결전- 설치 방법 - 업데이터 팝업 2](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-14.png)

```
게임이 실행중이므로 업데이트를 할 수 없습니다. 업데이터를 종료합니다.
```

란스 10을 이미 실행하고 있는 경우 위의 팝업을 볼 수 있다. 이 경우 게임을 잠깐 꺼 준 뒤에 다시 업데이트를 실행하도록 하자.

![Rance X -결전- 설치 방법 - 업데이터 팝업 3](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-15.png)

```
인스톨 폴더 E:\1. Gameroom\ランス１０에, 업데이트 파일을 복사합니다. 이대로 괜찮을까요?
```

앞서 게임을 ‘로케일 에뮬레이터’로 정상적으로 일본어 로케일로 설치했다면 위와 같은 팝업을 볼 수 있다.

업데이트 파일이 게임 설치 경로를 정상적으로 인식했기 때문에, 위처럼 설치 경로를 알아서 불러와서 여기에 설치하면 되냐고 묻는 것이다.

만약 로케일 에뮬레이터로 정상적으로 설치하지 않았다면 설치 경로를 수동으로 잡아줘야하는데, 이 경우 파일이 깨질 수 있으니 다시 정상적으로 로케일 에뮬레이터로 설치하는 것을 권한다.

![Rance X -결전- 설치 방법 - 업데이터 팝업 4](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-16.png)

```
업데이트를 성공했습니다.
```

위처럼 팝업이 떴다면 업데이트가 정상적으로 설치된 것이다.

이대로 1.02, 1.04 버전 설치도 진행하도록 하자.

![Rance X -결전- 설치 방법 - 게임 실행](https://subculturegamer.com/wp-content/uploads/2025/07/rance-x-setup-knowhow-17-1024x514.png)

설치가 모두 끝난 뒤, 게임을 실행한다. (물론 로케일 에뮬레이터로 실행한다.)

이때 게임 상단의 ヘルプ – バージョン情報 버튼을 누르면 게임의 버전을 볼 수 있다.

1.04라고 노출되면 정상적으로 설치된 것이다.
