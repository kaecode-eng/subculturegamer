## 0. 시작 전 반드시 할 일 (Git)

이번 세션에서 **`main` 히스토리를 다시 썼다**(민감 파일 1개를 전 커밋에서 제거 후 force-push). 예전 클론을 그대로 쓰면 지운 파일이 다시 올라갈 수 있다.

1. 기존 로컬 폴더는 백업만 해 두고 **새로 클론**하는 것을 권장한다.
   ```
   git clone https://github.com/kaecode-eng/subculturegamer.git
   ```
   기존 폴더를 계속 쓰려면, 로컬에만 있는 변경이 없는지 확인한 뒤:
   ```
   git fetch origin
   git checkout main
   git reset --hard origin/main
   ```
2. **이번 세션 작업은 아직 `main`에 없다.** 브랜치 `claude/subculturegamer-maintenance-3w31zg`에 커밋 12개가 있고 PR은 만들지 않았다. 둘 중 하나를 고른다.
   - GitHub에서 이 브랜치로 PR을 만들어 `main`에 병합 (권장)
   - 로컬에서 바로 이어서 작업: `git checkout claude/subculturegamer-maintenance-3w31zg`
3. 저장소는 **public**이다. 사내 자료, 내부 프로젝트명·캐릭터명, 개인 회고 초안 같은 내용은 커밋하지 않는다. 비공개 전환은 GitHub Settings에서 직접 할 수 있다(현재 포크 0).

## 3. 작업 원칙 (기존 + 이번 세션 추가)

- 블로그 공개·상태 변경은 **사용자 승인 후**에만.
- h2 섹션 사이에 구분자와 공백(SEP 규칙). 붙여 넣을 때는 공백 블록 + 구분선 + 공백 블록.
- 한국어 글은 마지막에 **humanize-korean**으로 윤문. 출력 끝의 `<!-- HUMANIZE-SUMMARY … -->` 블록은 반드시 지우고 저장한다(이번에 한 번 섞여 들어갔다).
- 저장 후 **객체 캐시 + LiteSpeed 캐시 + Cloudflare 캐시**를 비운다(Cloudflare는 WP Cloudflare Super Page Cache 메뉴).
- 이번 세션에서 확인한 WordPress 동작:
  - 글 편집 화면에서 올린 이미지는 **글의 작성 날짜 폴더**(예: `2024/08`)에 저장되고, 같은 이름이 있으면 `-1`, `-3`처럼 번호가 붙는다. 미디어 메뉴에서 올리면 현재 월 폴더. 어느 쪽이든 **글 속 이미지는 편집기에서 직접 교체**해야 한다(같은 이름으로 올려도 옛 주소는 살아나지 않는다).
  - 마크다운 `**“따옴표”**`처럼 따옴표에 붙은 굵게 표시는 붙여 넣을 때 변환되지 않는다. 툴바로 처리하거나 블록 HTML을 쓴다.
  - 붙여 넣기 본문은 **코드 편집기에 블록 HTML**로 넣는 방식이 가장 안정적이었다.
- 비공개 글 검토는 미리보기 화면을 **PDF로 인쇄**해 전달하는 방식이 가장 안전했다.

## 4. 환경·도구 메모

- **WordPress REST 인증 미해결**: 응용 프로그램 비밀번호를 썼지만 계속 401(`rest_not_logged_in`). 서버는 LiteSpeed(Vertex cPanel), 앞단 Cloudflare. `.htaccess` 맨 아래에 다음 두 가지를 추가했으나 해결되지 않았다.
  ```
  SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1
  RewriteEngine On
  RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]
  ```
  확인할 것: WP 관리자 → 도구 → 사이트 상태의 Authorization 헤더 경고 여부. 경고가 있으면 호스팅 지원에 헤더 전달 설정 요청, 없으면 응용 프로그램 비밀번호를 재발급하고 사용자명 철자를 다시 확인한다.
- **공개 글 가져오기**: [tools/import_posts_rest.py](../tools/import_posts_rest.py) (요구: `pip install markdownify`, `curl`). 공개 글만 가능.
- **통계**: [planning/traffic/README.md](../planning/traffic/README.md), `node tools/blog-stats.mjs --days 28`. 인증 파일은 Windows `AppData\Local\SubcultureGamerStats`에만 둔다.
- 이번 세션에서 만든 이미지 가림 처리본 zip과 블록 HTML은 클라우드 세션 임시 폴더에만 있었다. 필요하면 내려받아 둔 사본을 쓰고, 없으면 같은 방식으로 다시 만든다(블러가 아니라 큰 블록 모자이크 + 사전 블러로 처리해야 글자가 복원되지 않는다).
