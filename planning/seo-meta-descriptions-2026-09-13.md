# Bing 짧은 메타 디스크립션 개선안

첨부된 Bing Webmaster Tools 오류 목록의 50개 URL에 맞춘 권장 문안은 같은 폴더의 `seo-meta-descriptions-2026-09-13.csv`에 정리했다.

## 적용 원칙

- 각 URL의 현재 페이지 내용과 목적을 요약하고, 제목만 반복하지 않도록 작성했다.
- 일반 글, 홈, 카테고리·아카이브, 뉴스레터 페이지를 구분했다.
- SEO 플러그인(Rank Math, Yoast SEO 등)의 페이지별 메타 디스크립션 필드에 붙여 넣는다. CSV는 URL을 기준으로 일괄 작업할 때 사용한다.
- 실제 검색 결과 문구는 검색엔진이 바꿔 표시할 수 있다. 적용 뒤 사이트맵 갱신 또는 URL 검사 요청을 하고 2~4주 후 Bing에서 재확인한다.

## 주의할 항목

`gamedesign/page/3/` 같은 페이지네이션 아카이브는 검색 유입 가치가 낮다면 고유 설명을 넣기보다 SEO 플러그인에서 `noindex, follow`로 설정하는 편이 낫다. 이 설정은 사이트의 색인 정책에 영향을 주므로 현재 플러그인 설정을 확인한 뒤 적용한다.

이 저장소는 게시물의 본문·연결 정보를 보관하는 용도이며 워드프레스 사이트와 자동 연동되지 않는다. 따라서 이번 파일은 워드프레스 관리자에서 적용할 수 있도록 만든 작업용 목록이다.
