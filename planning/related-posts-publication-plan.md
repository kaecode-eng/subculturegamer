# 발행용 연관글 반영 계획

> 2026-07-17 · P3 1차 배치
>
> 목적: 검색 유입 독자가 현재 글을 읽은 뒤 같은 관심사의 다음 글로 이동하게 한다.

## 적용 원칙

- 한 글 하단에는 2~4개만 노출한다.
- 시리즈 중간편은 `이전 편 → 다음 편`을 가장 먼저 둔다.
- 완결편은 시리즈 첫 편 대신, 같은 주제의 심화·사례 글로 보낸다.
- 범용 입문글(MDA, Zero에서 시작하는 게임 디자인)은 정말 입문 독자에게만 1개 사용한다. 모든 글의 공통 연관글로 반복하지 않는다.
- 제목 앞의 `##`와 링크가 붙어 보이는 기존 형식 대신, 제목과 한 줄 설명을 분리한다.

## 공통 블록 형식

```markdown
## 다음에 읽으면 좋은 글

- [글 제목](URL) — 이 글을 읽은 뒤 이어지는 이유를 1문장으로 설명
- [글 제목](URL) — 비교하거나 바로 적용할 수 있는 다음 주제
```

## 1차 발행 배치: 완결 시리즈

### 퀘스트 디자인 6부작

각 편의 `related_posts` 메타데이터를 그대로 사용한다.

- 1편: 2편으로 이동
- 2~5편: 이전 편과 다음 편으로 이동
- 6편: 5편 + `10 페이지 컨셉 기획서` + `게임 기획자 1페이지 제안서`로 이동

6편 하단 문구:

```markdown
## 다음에 읽으면 좋은 글

- [퀘스트 디자인 5편](https://subculturegamer.com/game-quest-design-episode-planning-guide-2/) — 실무 가이드의 앞 단계를 먼저 확인합니다.
- [10 페이지 컨셉 기획서로 청사진 그리기](https://subculturegamer.com/10-page-concept-documents/) — 퀘스트 기획의도를 문서 구조로 옮기는 방법을 다룹니다.
- [게임 기획자 1페이지 제안서로 칼퇴하기](https://subculturegamer.com/1-page-proposal-for-game-designer/) — 기획서를 쓰기 전 협업 파트너와 합의하는 방법입니다.
```

### 게임 모션 기획 5부작

- 1편: 2편
- 2~4편: 이전 편 + 다음 편
- 5편: 4편 + `게임 캐릭터 컨셉 디자이너가 알아야 할 기본기 세 가지` + `미장센의 핵심, 카메라 워크 알아보기`

### 붕괴: 스타레일 온보딩 3부작

- 1편: 2편
- 2편: 1편 + 3편
- 3편: 2편 + `붕괴: 스타레일 이벤트 UI/UX` + `MDA 프레임워크로 로비 경험 디자인하기`

### 란스X 시스템 분석 3부작

- 1편: 2편
- 2편: 1편 + 3편
- 3편: 2편 + `CCG와 전투 메타에 대한 짧은 생각` + `금빛 러브리체와 미연시 시스템 분석`

### 창세기전 템페스트 분석 4부작

- 1편: 2편
- 2편: 1편 + 3편
- 3편: 2편 + 캐릭터 분석
- 캐릭터 분석: 3편 + `게임 시나리오 5대 연출 요소` + `화합의 도시 페나코니의 메타포 분석`

### 초단편 스토리 7편

- `초단편 소설 쓰기`를 시리즈 입구로 두고, 각 단편은 발행 순서의 앞뒤 글을 연결한다.
- 마지막 `미식연구회의 기묘한 하루`에는 `블루 아카이브 시나리오 포스트모템 리뷰`를 덧붙여 팬 창작에서 게임 분석으로 넘어가게 한다.

## 반영 확인 체크리스트

- URL은 발행 직전에 각 글 frontmatter의 `url`과 대조한다.
- 한 시리즈의 순서가 바뀌면 `series_order`와 본문 하단 링크를 함께 바꾼다.
- 발행 뒤 모바일에서 연관글이 1줄로 뭉치지 않고, 항목별로 분리되어 보이는지 확인한다.
- 4주 뒤 Search Console 또는 WordPress 통계에서 연관글 클릭·세션당 페이지 수 변화를 확인한다.

## 아직 발행용 목록을 만들지 않은 글

일상, 장비 후기, 단발 게임 소개처럼 독자 의도가 독립적인 글은 억지로 연결하지 않는다. 해당 글들은 다음 신규 글이 생겨 문맥상 맞는 연결이 생길 때만 1~2개를 추가한다.
