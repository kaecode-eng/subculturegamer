## 이미지 교체 공통 절차

1. 미디어 라이브러리에서 원본 첨부 파일을 삭제한다(2026-11-12 완료). 새로 올린 파일은 `2026/11` 폴더에 저장되므로 글 속 이미지는 편집기에서 직접 교체해야 한다.
2. 가림 처리본(세션에서 전달한 zip)을 업로드하고 글 속 이미지를 교체한다.
3. 객체 캐시, LiteSpeed 캐시, Cloudflare 캐시를 비운다.
4. 원본 이미지 주소가 404인지 확인한다.

## 2편 saas-cowork

- [x] 본문 "트렐로 문제 정의" 보드 캡처를 삭제했다(2026-11-12). 가림 처리본은 알아보기 어려워 넣지 않기로 했다.
- 원본 크기 파일과 WordPress가 만든 축소본 모두 지워야 한다(첨부 파일 삭제로 함께 지워진다).
- 제안서 슬라이드 4장(낯설게하기·Wiki·간트 차트·A/B 테스트)에는 로고가 없어 그대로 둬도 된다.

## 3편 도입기 (ID 10345)

- 초안의 `(업로드: 파일명)` 자리를 실제 이미지 주소로 바꾼다.
- 원문 후반부 이미지(용어, 칸반, 뷰, 자동화 규칙 슬라이드 약 30장)는 본문에서 빠지므로 미디어 라이브러리에서 삭제한다. 용어 피라미드(`image-2.png`)만 4편으로 옮긴다.
- 발행 전 편집 메모(HTML 주석)를 지운다.

## 4편 실무자 가이드

- [ ] 블러와 회색 박스가 **이미지 파일 자체**에 들어갔는지 확인: 이미지를 새 탭에서 열어 원본이 보이지 않아야 한다. 특히 iCal 동기화 주소 이미지(토큰이 보이면 작업 목록이 유출된다).
- [ ] 예시 "아레스 캐릭터 컨셉 기획서"가 실제 프로젝트의 캐릭터명이면 가상의 이름으로 교체.
- [ ] 3편에서 옮겨 오는 용어 피라미드(포트폴리오 > 프로젝트 > 섹션 > 작업 > 하위 작업)를 "홈 화면 익숙해지기" 앞에 넣는다.
- [ ] 태그를 팀 협업으로 변경.

## 5편 관리자 가이드

- [ ] "현재가 M10이고 M11에 캐릭터 3체, USP 1개/2개" 예시와 커스텀 필드 화면의 M10 값이 실제 일정과 같다면 "M3, 캐릭터 2체"처럼 바꾼다.
