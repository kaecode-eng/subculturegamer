## 시리즈 개요

나니노벨(Naninovel) 공식 문서 한국어 번역 + 실전 가이드 시리즈 (2024-08 ~ 2025-03). Unity 기반 비주얼 노벨 엔진의 전 기능을 커버하는 45편 이상의 시리즈.

## 진행 현황

### 기본 기능 (완료)
- Introduction, Getting Started, Scripts, Text Printers, Characters, Backgrounds
- Audio, Voicing, Choices, Movies, Special Effects, Transition Effects
- IDE Extension, Development Console, Playmaker, Visual Scripting

### 저장·설정 시스템 (완료)
- Save-Load System, Game Settings, Input Processing, Compatibility

### 커스터마이징 (완료)
- Custom Commands, Custom Variables, Unlockable Items, Managed Text
- Custom Actor Implementations, Custom Actor Shader
- Custom Configurations, Custom Script Parser
- Engine Architecture, Engine Services, State Management

### 고급 기능 (완료)
- Integration Options, Render Pipelines, Automated Testing
- Custom Build Environment, Samples, Community Modding

### 국제화 (완료)
- Localization, Script Expressions
