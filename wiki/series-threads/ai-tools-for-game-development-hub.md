AI가 게임 기획자의 역할을 어떻게 바꾸는지 이해한 뒤, 기획 검토와 학습 계획, 이미지 제작에 적용하는 경로다.

## 읽는 순서

전망은 [[posts/published/ai-game-design-gdc-2026-trends]]와 [[posts/published/ndc-2026-insights-from-3-session]]에서, 기획 검토는 [[posts/published/2026-07-19-game-planning-ai-cross-validation-gpt-claude]]에서 다룬다. 기획자가 작은 프로토타입과 반복 업무 도구를 만드는 흐름은 [[posts/published/2026-10-04-game-designer-vibe-coding]]으로 이어진다. 이미지·엔진 실습은 [[posts/published/chatgpt-unity-learning-planning]] → [[posts/published/stable-diffusion-setup]] → [[posts/published/stable-diffusion-txt2img]] → [[posts/published/comfyui-subculture-bishojyo-making-with-illust]] 순으로 확장한다.

## 2026-10~11 추가 연결

- `2026-10-31-comfyui-visual-novel-standing-sprite.md`: 기획자 1인이 ComfyUI(Anima Turbo)로 하루 만에 비주얼노벨 스탠딩 한 벌(표정, 눈 깜빡임, 립싱크, 누끼)을 만든 제작기.
- `2026-11-08-claude-code-comfyui-visual-novel-retrospective.md`: Claude Code + Unity MCP로 기획서를 작업 단위로 쪼개 개발하고 AI 플레이테스트까지 맡긴 비주얼노벨 버티컬 슬라이스 회고. 내러티브 디자이너 포트폴리오의 새 형태로서 [[wiki/concepts/vibe-coding-for-game-design.md]]의 실전 사례다.
